# 合作慣例

- 使用者以繁體中文溝通；回覆用繁體中文。程式碼註解、commit message 維持英文（跟現有 repo 一致）。
- **直接 push `main`**，不開 branch、不開 PR。使用者明確說過不需要 branch。
- 新需求寫在 `sidecar` branch 的 `genesis/FIAT-{feature}.md`，由使用者維護。
  完成後**複製**（不是 merge）到 `main` 的 `genesis/`；若需求本來就已滿足，則不加該檔，
  只 commit 實際改動，message 寫明改了什麼。
- `main` 的 `genesis/FIATLUX.md` 是專案最初的規格（原本叫 SPEC.md）。
- README 開頭的 AI model declaration 由使用者指定寫 **Claude Opus 5.5**（2026-10-17 從 5.0 改過來）；
  `pyproject.toml` 的 Authorship 註解還寫 5.0，使用者沒要求改。
- viewer 要能用手機操作：**說明裡提到的每個按鍵都要有對應的按鈕**（底部按鈕列「« ◀ ▲ ⤢ ▼ ▶ » log」，
  說明裡每個按鍵旁註明手機上點哪裡）。新增快捷鍵時記得同時加按鈕與說明。
  使用者偏好（2026-10-17）：手機版由上而下「總成績 → 排行榜 → 個股細節」；同一功能不要出現兩組按鈕
  （所以手機上隱藏排行榜上方的換月按鈕）；「第一／最後」用 « » 而不是文字。
  排行榜一律依排名排序，不要為了方便把任何列「釘」到不符排名的位置（目前檢視的未上榜股票放在它的名次上）。
- 使用者會中途打斷並調整方向；長時間工作（下載、回測）先講清楚要做什麼、大約多久。
- **2026-10-16 明確授權**：執行程式不必問；從開工一路做到推上 GitHub Pages，中間不要停下來問，
  有問題自己想最佳解，重大決定寫進 `CALLBACK.md` 但不必等回覆。（權限檢查擋下的事例外：那只能請他在對話裡同意。）
- 雲端環境這邊的 git proxy 不允許刪除遠端 branch（403），需要刪 branch 時請使用者在 GitHub 上刪。

## 使用者的交易與研究偏好（2026-10-16 確認，不必再問）

- **券商手續費沒有折扣**：0.1425% 全額＋賣出證交稅 0.3%，就是 `config.py` 現值，不要再問折數。
- **晚上選股、隔天白天馬上下單**：回測的「t 日收盤算分、t+1 日成交」正好對應，不要設計「選完隔好幾天才下單」的流程。
- **大盤濾網**：若分數本身就能在崩盤時退場，就不要加大盤濾網（偏好單一機制）。
- **權重**：想比較等權重與依分數動態權重（`weighting`）；直覺上喜歡分數權重「讓不適合的股票漸漸離開」。
- **結果呈現**：下一個 FIAT 會要求新 viewer。超參數實驗要「計算」與「輸出」分開，
  計算結果存檔 commit，之後只重跑輸出就能看，不要逼他重跑整個參數空間。
- **誠實優先於好看**（2026-10-17）：使用者接受朋友 AI「看過答案」的批評，要求照實重跑；不看答案的結果比較差也照用。
  評論來自別的 AI 時，逐點用資料查證後再回答（例如「好股票變便宜」那點只對一半）。
- 模式選單維持「自動」（不是「接受編輯」）；`.claude/settings.json` 的 allow 規則要使用者自己 commit，
  Claude commit 會被擋（Self-Modification）。
