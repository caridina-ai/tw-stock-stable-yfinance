排行榜：每次換股時，通過流動性與股價門檻的股票依分數排序的前 50 名， 再加上不在前 50 名但仍持有（遲滯規則）或剛被剔除的股票。 成分股依「已經連續持有多久」由黃轉紅；被剔除的依「剔除多久了」由深綠漸淡（12 個月後不再上色）。 本次剔除的股票顯示「買進價→賣出價 報酬」：價格是買進與賣出那天的實際收盤價（未還原）， 報酬用還原股價算、含期間股利，未扣交易成本（約 0.6%）；滑鼠停在上面可看日期與持有月數。

K 線：還原股價。藍色底色是當次選股用的回推範圍，藍線是該範圍的對數線性迴歸（延伸到整個畫面）， 虛線是 ±1σ；放大時橘色短線是「一致性」各子段各自的迴歸。圖下方色帶是這檔股票被持有的期間。 下方子圖是這檔股票每次換股算出的分數，Y 軸範圍固定為本實驗所有曾上榜股票的分數範圍，方便比較； 虛線是買進門檻。空心點表示當時不符流動性或股價門檻。

Walk-forward 實驗每一折的參數不同（回推天數、分數形狀、門檻），所以分數在折與折之間會跳動， 這是真的，不是畫錯。分數與排名是程式算的正式值；下方的分項是瀏覽器依存成 0.05% 精度的股價重算， 與正式分數可能差千分之幾。
